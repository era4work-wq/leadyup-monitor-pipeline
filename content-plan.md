# Контент-план: модели, инфраструктура, стоимость

Цифры целей (сколько чего в месяц) — в `content-plan.json`, правится отдельно и без пересчётов. Этот файл — пояснение, откуда цены и что именно их считает, зафиксировано 01.08.2026.

## Инфраструктура генерации

Весь текст в пайплайне пишется через **OpenRouter** (`OPENROUTER_API_KEY`, секрет GitHub Actions) — это отдельная pay-as-you-go API-биржа со своим пополняемым балансом, **не подписка Claude.ai/Claude Code**, которой пользуются в этом чате, и не прямой ключ к Anthropic/OpenAI/Google API — их в коде нигде нет, весь ИИ-трафик идёт только через OpenRouter.

Что НЕ идёт через OpenRouter и вообще не ИИ:
- Сама картинка баннера — готовое фото с Google Диска + текст поверх, наложенный HTML-рендером (Playwright), без участия модели.
- Google Drive API, Telegram/Max/VK Bot API — доставка и хранение, свои ключи.
- GitHub Actions — оркестратор расписаний, тоже не ИИ.

## Модели по стадиям

| Стадия | Модель | Почему |
|---|---|---|
| Написание текста (пост RU/EN, статья, карусель RU/EN) | Claude Opus 4.5 | Творческое письмо — нужна связность на длинных текстах (перешли с Sonnet из-за жалоб на связность) |
| Оба прохода антидетектора | Claude Opus 4.5 | Та же модель, что пишет черновик |
| Отбор тем из RSS | Claude Haiku 4.5 | Классификация/фильтр, не творческое письмо — дёшево |
| План «по болям» (раз в неделю) | Claude Haiku 4.5 | Тоже выбор + короткое обоснование, не полноценное письмо |
| Подбор папки баннера в Drive | Claude Haiku 4.5 | Сопоставление темы с названием папки |
| Генерация обложки (Gemini 2.5 Flash Image) | — | В коде есть, но ВЫКЛЮЧЕНА — ломала кириллицу на картинке |

## Стоимость по форматам (оценка по размеру промптов и типичной длине ответа)

Точные цифры по каждому запросу — в кабинете OpenRouter → Activity, это авторитетнее любой прикидки здесь.

| Формат | Цена за штуку |
|---|---|
| Пост RU | ~$0.08–0.13 |
| Пост EN | ~$0.05 |
| Карусель RU | ~$0.10 |
| Карусель EN | ~$0.10 |
| Статья | ~$0.25–0.30 |
| План «по болям» (на 4 боли разом) | ~$0.01/неделю (~$0.04/мес) |
| Отбор тем + подбор баннера | копейки |
| Отчёт о темпе (`report_progress.py`) | $0 — не вызывает модель вообще, чистый подсчёт по данным |

## Расчёт на месяц по текущему плану (`content-plan.json`)

При целях 10 статей (7 мониторинг + 3 боли), 2 поста/день, 1 карусель/день, 4 боли/неделю:

- Статьи: 10 × ~$0.27 ≈ **$2.7**
- Посты: ~60/мес (≈17 по болям, ≈43 с мониторинга) ≈ **$4.7**
- Карусели: ~31/мес (RU+EN, если весь объём дублируется на оба языка) ≈ **$3–6**
- План «по болям»: ~$0.04

**Итого ориентировочно $10–15/месяц** на генерацию текста при полном соблюдении графика. Если объём вырастет (например, весь контент начнёт дублироваться в EN) — это первое, что стоит пересчитать.

**Кто платит:** ключ `OPENROUTER_API_KEY` привязан к чьему-то аккаунту OpenRouter с пополняемым балансом — на момент фиксации (01.08.2026) точно не установлено, чей именно это аккаунт (агентства или собственника LeadYup). Проверяется через логин на openrouter.ai под тем аккаунтом, где создавался ключ.
